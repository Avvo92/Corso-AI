# Sessioni capitolo — diario persistente (Modulo 3 — DL & CV)

Questa cartella contiene **un file Markdown per capitolo** del Modulo 3 in cui il mentor annota, durante lo studio:

- domande che fai mentre lavori sul file `.py` del capitolo;
- valutazioni e correzioni quando chiedi feedback su esercizi, quiz o mini-esercizi;
- pattern ricorrenti e note per il **rinforzo** nel capitolo successivo.

## Convenzione di naming (Modulo 3)

Per il capitolo il cui file è ad esempio `01_neurone_artificiale.py`:

- nome diario: **`M03_C01_neurone_artificiale_sessione.md`**
  - `M03` = Modulo 3
  - `C01` = prefisso numerico del file capitolo (`01_`)
  - `neurone_artificiale` = parte del nome file dopo il numero

Regola pratica: **`M03_C{NN}_{resto_nome_senza_estensione}_sessione.md`**

## Come si usa

1. **All'inizio** di un nuovo capitolo: copia `_TEMPLATE_sessione_capitolo.md` con il nome corretto (oppure crealo direttamente).
2. **Durante** il capitolo: a ogni richiesta di valutazione/correzione, il mentor **appende** una voce.
3. **In chiusura capitolo**: il mentor legge questo file **insieme** a `CONTESTO_CORSO.md`, `APPUNTI_APPLICATIVO.md` e l'archivio del modulo precedente.

Vedi anche `CONTESTO_CORSO.md` — Regola **39** e sezione **J)** del Protocollo Anti-Perdita Contesto.
